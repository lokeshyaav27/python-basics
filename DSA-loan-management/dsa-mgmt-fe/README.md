# dsa-mgmt-fe

Vite + React + TypeScript starter for DSA Management front-end.

Setup:

```bash
cd dsa-mgmt-fe
npm install
npm run dev
```

Installed libraries (declared in package.json): i18next, react-i18next, redux, @reduxjs/toolkit, react-redux, @tanstack/react-query, antd, tailwindcss, axios, crcf

Next steps:
- Run `npm install` to fetch dependencies
- Start dev server with `npm run dev`
- Configure Ant Design theming and import as needed
- Adjust i18n resources in `src/i18n.ts`
